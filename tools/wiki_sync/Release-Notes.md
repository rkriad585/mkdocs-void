# Release Notes

## v0.2.2 (latest)

- **Glass system** — configurable intensity (light/medium/heavy)
- **Action cluster** — floating menu with customizable actions
- **Focus timer** — built-in Pomodoro-style timer with TOC ring
- **Notes panel** — inline note-taking with localStorage persistence
- **Config builder** — visual YAML editor in the action cluster
- **Repo popover** — GitHub data card (stars, forks, language, etc.)
- **PWA manifest** — auto-generated `manifest.webmanifest`
- **Service worker** — offline caching for static assets
- **Reading mode** — distraction-free view with section hiding
- **Search deep links** — `?q=` URL param opens search with query
- **Dark-aware images** — automatic light/dark src swap
- **Link rebase** — dev preview rewrites production URLs to localhost
